Capital, fees, alerts and data. Changes rebuild every pot's history from the start date.

How edits are saved

Running on your computer: edits are saved straight to config/portfolio.yaml.

On the hosted site, edits are sent to your GitHub repository, which rebuilds the site in about 2 minutes. Paste a fine-grained GitHub token once (stored only in this browser). Give it access to this repository only, with Contents: read and write and Actions: read and write.
